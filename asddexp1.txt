Practical 1: Version Control Operations Using Git

Steps

1. Initialize the repository
Open PowerShell or the VS Code terminal and run:
mkdir "Student Management System"
cd "Student Management System"
git init

2. Create the student file
Run notepad student.txt. Add sample student details and save the file.

3. Stage and commit
Run:
git add student.txt
git commit -m "Initial commit"

4. Create a GitHub repository
Create a new repository on GitHub named Student-Management-System.

5. Link and push to GitHub
Replace YOUR_USERNAME with your GitHub username:
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/Student-Management-System.git
git push -u origin main

6. Create a feature branch
Run git checkout -b feature-update.

7. Update student records
Open student.txt, add another student record, and save it.

8. Commit and push the branch
Run:
git add student.txt
git commit -m "Added new student records"
git push -u origin feature-update

9. Merge into main
Run:
git checkout main
git merge feature-update
git push origin main

10. Check history and status
Run git log --oneline, git status, and git branch.

Conclusion
• Git was used to initialize and manage a local repository.
• A student information file was created and committed.
• The local repository was connected to GitHub.
• A feature branch was created to make changes independently.
• The feature branch was merged into the main branch.
• Git commands helped track changes and display commit history
