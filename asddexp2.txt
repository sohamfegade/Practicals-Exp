Practical 2: CI/CD Using GitHub Actions and Jenkins

Steps

1. Create a Node.js project
Install Node.js, then run:
mkdir CICD-Demo
cd CICD-Demo
npm init -y
npm install --save-dev jest

2. Create the application
Create app.js with a function that adds two numbers and export it using module.exports.

3. Create the test file
Create app.test.js and write a Jest test that checks whether add(2, 3) returns 5.

4. Configure package.json
Set the scripts to:
"test": "jest",
"build": "node --check app.js" Keep the other existing fields.

5. Test locally
Run npm test and confirm the test passes.

6. Push project to GitHub
Create an empty GitHub repository, then run:
git init
git add .
git commit -m "Initial CI CD project"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/CICD-Demo.git
git push -u origin main

7. Create GitHub Actions workflow
Create .github/workflows/ci.yml. Configure it to check out the code, set up Node.js, install dependencies, run tests,
and run the build check.

8. Push and verify workflow
Run git add ., git commit -m "Add GitHub Actions workflow", and git push. On GitHub, open the Actions tab and
check the workflow result.

9. Install and open Jenkins
Install Java and Jenkins, start Jenkins, open http://localhost:8080, complete setup, and ensure Git and Node.js are
available.

10. Create a Jenkins Pipeline
In Jenkins, choose New Item → Pipeline. Configure stages named Checkout, Install, Test, and Build. Use the
repository URL and suitable Windows bat or Linux sh commands.

11. Run and capture results
Click Build Now, open Console Output, verify successful stages, and capture screenshots of GitHub Actions and
Jenkins output.

Conclusion
• A simple Node.js application was created and tested using Jest.
• GitHub Actions was configured to automate testing after code changes.
• Jenkins was configured to execute pipeline stages.
• Both tools helped automate software development tasks.
• CI/CD reduces repetitive manual work and improves consistency.
• Automated testing helps detect errors earlier in development.
