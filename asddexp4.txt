Practical 4: Containerizing Applications Using Docker

Steps

1. Install Docker Desktop
Install Docker Desktop from docker.com/products/docker-desktop and wait until the Docker engine is running.

2. Verify Docker
Run:
docker --version
docker info

3. Create the project folder
Run:
mkdir DockerDemo
cd DockerDemo

4. Create Java program
Create Hello.java and add a Java main method that prints Hello Docker World.

5. Create Dockerfile
Create a file named exactly Dockerfile (no extension) with:
FROM eclipse-temurin:21-jdk
WORKDIR /app
COPY Hello.java .
RUN javac Hello.java
CMD ["java", "Hello"]

6. Build the Docker image
Run docker build -t dockerdemo . from inside the DockerDemo folder.

7. Verify the image
Run docker images and confirm that dockerdemo appears.

8. Run the container
Run docker run dockerdemo. The expected output is Hello Docker World.

9. Check container status
Run docker ps -a. The container will usually show Exited (0) after the program finishes successfully.

10. Inspect logs
Open Docker Desktop and inspect the container logs and execution details.

Conclusion
• Docker Desktop was installed and verified.
• A simple Java application and Dockerfile were created.
• A Docker image was built successfully.
• The application was run inside a Docker container.
• The container displayed the expected Hello Docker World output.
• Docker packages applications for consistent execution across environments.
