Practical 3: Scrum-Based Agile Project Management in Jira

Steps

1. Open Jira
Sign in or create an account at atlassian.com/software/jira.

2. Create a Scrum project
Choose Create project, select the Scrum template, and name the project Online Library Management System.

3. Configure workflow columns
Configure the board columns as To Do, In Progress, In Review, and Done.

4. Create four work items
Create two Tasks, one Story, and one Bug. Example: Design library homepage (Task), Create book database (Task),
Search for books (Story), and Fix book search error (Bug).

5. Add details and priorities
Enter a description and priority for each work item.

6. Organize the backlog
Open the Backlog and arrange the four work items in priority order.

7. Create a sprint
Create a sprint named Sprint 1 and add all four work items. Set the duration if prompted and start the sprint.

8. Move an item through workflow
Move at least one item through To Do → In Progress → In Review → Done.

9. Invite a team member
Open the project access or people settings and invite a team member, or demonstrate the invite feature if required.

10. Verify and capture evidence
Check the backlog, sprint, priorities, descriptions, and statuses. Take screenshots if required.

Conclusion
• A Scrum project was created in Jira.
• Tasks, a story, and a bug were added with priorities and descriptions.
• The work items were organized in the backlog and added to a sprint.
• The workflow was used to track work from To Do to Done.
• Jira helps team members organize and monitor project work.
• Agile project management supports collaboration and iterative delivery.
